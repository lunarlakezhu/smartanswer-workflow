# 审计报告模板

> 用途：主 agent 汇总 audit.js 输出后按此模板落盘 `r1\audit_report_r1.md` / `r2\audit_report_r2.md`。
> 锁定后本报告即禁改清单；二轮增量审计追加「防回退」结果。

```
# 审计报告 · B阶段
## 审计概要
- 审计时间、全文覆盖 {M} 通过/{M1} 回退、声明总数 {N}
- ✅ {X} / ⚠️ {Y} / 🔄 {Z1} / 🚫 {Z2}，可信度 {X/N*100}%
## 对照明细
| # | 声明摘要 | 引用 | 原文文件 | 原文行号 | 原文摘句（≤40字） | 结果 | 说明 |
```

> 判定口径：✅ 原文确认 / ⚠️ 部分匹配（陈述超出原文或改写失真）/ 🔄 综述代引（需溯源原始 DOI）/ 🚫 无原文支撑。
> 连字归一化：ef fi ciently → efficiently；MinerU ff→f 静默丢失按归一化后匹配。
> 覆盖度附注：主 agent 用 pwsh 统计各归档 [N] 引用行号的前/中/后三等分分布；全部集中前 1/3 → 回溯重读（不派 LLM 子代理）。
