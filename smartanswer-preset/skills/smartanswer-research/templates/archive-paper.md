# 归档模板 · 普通文献（六维 + 思考三问）

> 用途：主读子代理按此模板产出归档段落（**不含「全文内容」段**，全文由主 agent 用 pwsh 追加）。
> 说明：{} 为占位符，需按实际文献填写；「全文内容」段必须逐字取自转换后的 md 全文。

```
来源: {期刊/出版商}  标题: {完整标题}  作者: {全部作者}
年份: {年份}  期刊: {期刊名}  DOI: {DOI}
================================================================================
                                六维精读
================================================================================
研究问题/动机：  方法/创新点：  实验设置：
关键结果：  局限性（仅作者自述）：  全作者列表：
================================================================================
                                思考三问
================================================================================
① 解决了什么前人没解决的问题？
② 复现最大难点在哪？
③ 局限对调研主题的影响？
================================================================================
                                全文内容
================================================================================
{论文全文（连续段落）——主 agent 追加，子代理不输出}
================================================================================
信息来源等级：(A)  交叉验证状态：{✅双读一致/差异已仲裁/📌单源}
双读结果：{验证读补充/差异}
```
