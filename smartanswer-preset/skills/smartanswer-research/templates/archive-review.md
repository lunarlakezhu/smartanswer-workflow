# 归档模板 · 综述（观点提炼）

> 用途：主读子代理按此模板产出归档段落（**不含「全文内容」段**，全文由主 agent 用 pwsh 追加）。
> 要求：观点提炼**不遗漏任何独立观点**，每条带出处段落。

```
来源: {期刊/出版商}  标题: {完整标题}  作者: {全部作者}
年份: {年份}  期刊: {期刊名}  DOI: {DOI}
================================================================================
                                观点提炼
================================================================================
1. 领域背景/问题定义
   - 观点1（出处段落）
2. 主要技术/方法分类
   - 分类A：代表工作（出处段落）
3. 关键挑战/开放问题
   - 挑战1（出处段落）
4. 趋势/展望
   - 趋势1（出处段落）
================================================================================
                                全文内容
================================================================================
{论文全文（连续段落）——主 agent 追加，子代理不输出}
================================================================================
信息来源等级：(A)  交叉验证状态：{✅双读一致/差异已仲裁/📌单源}
双读结果：{验证读补充/差异}
```
