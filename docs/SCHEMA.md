# SCHEMA · new-library 元数据、命名与版本规范

> 本文件定义库的命名规则、文件格式、标签词表、信息等级、去重与版本管理规则。
> 任何新增/修改文件都应遵守，以保证 agent 可稳定读取、不虚构、不遗漏。

## 1. 目录职责
- `文献索引.md`：主索引，唯一权威元数据表（编号↔标题↔期刊↔年份↔DOI↔各文件存在性）。
- `md/`：论文正文（mineru 全文 或 人工摘要卡片）。**内容类型不纯，已通过 frontmatter `类型` 字段区分，agent 读前先看 frontmatter。**
- `pdf/`：原始 PDF，作为"原文真相源"。
- `归档/`：精读笔记（六维精读 / 综述精读 / 摘要卡片 / 精读笔记），结构化 `## 文献信息` + 论点。
- `最终回答汇总/`：跨论文主题综合报告；报告内引用用内部 `[n]`，须映射回全库编号。
- `CHANGELOG.md`：版本与去重记录（规模、空缺、漂移、修正留痕）。

## 2. 编号规则（主键）
- 格式：`001`–`536`（3 位零填充，十进制递增）。**文件名用 3 位零填充。**
- 索引列 `编号` **已统一为 3 位零填充**（`001, 010, 100, 536`），与文件名前缀完全一致，无需任何映射。agent 检索时索引编号即可直接拼文件名。
- 空缺编号 = 已移除/合并，不补号、不复用。
- 新增论文：取当前最大号 +1；与已删号主题重复则先查重。

## 3. 文件命名
- 推荐：`编号_短slug.扩展名`（如 `003_dea_review.md`），slug 用 ascii 安全短词，**不要硬截断英文标题**。
- 兼容现状：`编号-英文标题截断-期刊截断-年份.md`（靠前缀编号识别）。
- **扩展名一致性**：`md/` 下已统一为 `.md`（原 42 个 `.txt` 已完成重命名，0 冲突）。

## 4. 文件 frontmatter（已实施）
每个 `md/` 与 `归档/` 文件头部**已注入**如下 YAML frontmatter（2026-08-18 批量写入，覆盖全部 810 个 .md）：
```yaml
---
编号: "003"                       # 3 位零填充，与文件名前缀一致
类型: "full-text"                # 五选一，见下表
标题: 完整英文标题
期刊: 全称或标准缩写
年份: 2026
信息等级: "A"                     # 仅 六维精读/摘要卡片 有值；全文/综述/精读笔记为空
DOI: 10.xxxx/xxxx
主题: ["DEA", "介电弹性体", "综述"]   # 启发式关键词分类，1–5 个
---
```
**`类型` 字段取值（区分"全文 vs 卡片/笔记"的关键，agent 必读）**：
| 值 | 含义 | 来源特征 |
|----|------|---------|
| `full-text` | mineru 全文转换（数十~数百 KB） | 无 信息等级/信息来源等级，仅原始正文 |
| `摘要卡片` | 人工摘要卡片（含 信息来源等级） | 含 `信息来源等级` 字段 |
| `六维精读` | 六维精读笔记（含 信息等级 A/B/C） | 含 `信息等级` 字段 |
| `综述精读` | 综述类精读笔记 | 含 `类型: 综述` |
| `精读笔记` | 其他结构化精读笔记 | 含 `## 文献信息` 结构块 |

> 注：`主题` 为**启发式关键词**，仅供检索筛选参考，不保证穷尽；需精确主题归属时仍以正文为准。`信息等级` 为空表示未做单篇评级（如全文、综述），不代表可信度低。

## 5. 信息等级定义
- **A**：已读全文/精读笔记完整，细节可断言。
- **B**：读过主要章节，核心结论可用，细节需回原文核实。
- **C**：仅有卡片或标题级信息，**引用时必须标注"待核实"**。

## 6. 主题标签受控词表
- 驱动方式：DEA/DEFA、SMA、PCM相变、磁驱动、气动液压、刚柔耦合、肌腱、折纸、阻塞、其他
- 应用场景：水下、狭窄空间、深海、抓取、触觉传感、仿生控制/CPG、生物体操作
- 文献类型：综述、原创研究、方法
> 每篇打 1–3 个标签，写入 frontmatter 与索引"主题标签"列。

## 7. 去重规则
- **论文级去重以 DOI 为准**：同一 DOI 只保留一个编号（"主编号"）。
- 检测结果（2026-08-18 只读扫描）：跨编号 DOI 重复 **0** 处、标题重复 **0** 处、编号复用 **0** 处、孤儿文件 **0** 处 → 当前库已干净，无需合并删除。
- 若日后发现重复：保留信息最全者为主编号，其余标记 `备注: 重复→主编号XXX` 并保留别名归档，不直接物理删除（便于溯源）。
- 同一编号内 `md/` 全文与 `归档/` 笔记为"分层"而非"重复"，不视为去重对象。

## 8. 版本管理
- 所有规模/结构变更写入 `CHANGELOG.md`（日期 + 操作 + 影响编号）。
- 索引 `md/pdf/归档` 存在性标记必须与磁盘真实状态一致；发现漂移立即修正并在 CHANGELOG 留痕（如 305、318 的 `md` 标记误标 ✅，已记录待修）。
- 编号空缺、历史移除号在 CHANGELOG 登记，使"少了号"可解释。
- 不覆盖旧版原文；重大修订新增编号而非原地改写。

## 9. 引用与溯源（不虚构底线）
- 任何综合回答必须能回溯到 `编号 + DOI + 文件名`。
- 主题报告引用论文时，在"文献总览"表加"全库编号"列，把内部 `[n]` 映射到本库编号。
- 外部来源库（ZhuLibrary / SmartAnswer-Library / HanaLibrary）若不在本库，须标注"原文见外部库"，不得假装本库含原文。
